# 🛍️ Brazilian E-Commerce (Olist) Database & Dashboard

## 📖 Project Overview
This project is a complete data engineering and analysis pipeline based on the Brazilian E-Commerce Public Dataset by Olist. It covers the entire lifecycle of database development, including ETL, complex SQL analysis, performance optimization, and an interactive Streamlit web dashboard.

## 📂 Repository Structure
- **`data/`**: Raw CSV datasets (or instructions on where to download them).
- **`sql_scripts/`**: DDL for schema, DML for analysis queries, and Trigger scripts.
- **`python_scripts/`**: ETL pipelines, data visualization, and the Streamlit app.
- **`docs/`**: Final PDF report, ER Diagram, and dashboard screenshots.

## 🚀 Key Features
1. **Database Design**: Fully normalized 3NF relational schema with Primary and Foreign keys.
2. **ETL Pipeline**: Python scripts to clean missing values and load data into PostgreSQL.
3. **SQL Analysis**: 8 complex queries (Joins, Subqueries, Views, Stored Procedures).
4. **Performance Tuning**: Index optimization using `EXPLAIN ANALYZE`.
5. **Interactive Dashboard**: Streamlit app displaying KPIs and visualizations.
